# Modules (Gemstones)

Modules are the equivalent of "Gemstones" from Backpack Battles. They can be socketed into items for bonuses.

## Module Types

### Performance Module (Ruby)
- **Shape:** 1x1 (1 slot)
- **Effect:** +4/8/12/16/20% Critical hit chance (based on tier)
- **Cost:** 1/2/4/8/16 Gold (based on tier)
- **Tiers:** Chipped/Flawed/Regular/Flawless/Perfect
- **Description:** Optimizes code paths for critical strikes
- **Backpack Battles Equivalent:** Ruby

### Memory Module (Sapphire)
- **Shape:** 1x1 (1 slot)
- **Effect:** +1/2/3/4/5 Memory (based on tier)
- **Cost:** 1/2/4/8/16 Gold (based on tier)
- **Tiers:** Chipped/Flawed/Regular/Flawless/Perfect
- **Description:** Additional RAM for enhanced capabilities
- **Backpack Battles Equivalent:** Sapphire

### Processing Module (Topaz)
- **Shape:** 1x1 (1 slot)
- **Effect:** +1/2/3/4/5 CPU regeneration (based on tier)
- **Cost:** 1/2/4/8/16 Gold (based on tier)
- **Tiers:** Chipped/Flawed/Regular/Flawless/Perfect
- **Description:** Accelerates CPU recovery
- **Backpack Battles Equivalent:** Topaz

### Efficiency Module (Emerald)
- **Shape:** 1x1 (1 slot)
- **Effect:** +10/20/30/40/50% Attack speed (based on tier)
- **Cost:** 1/2/4/8/16 Gold (based on tier)
- **Tiers:** Chipped/Flawed/Regular/Flawless/Perfect
- **Description:** Streamlines execution for faster attacks
- **Backpack Battles Equivalent:** Emerald

### Security Module (Amethyst)
- **Shape:** 1x1 (1 slot)
- **Effect:** +4/8/12/16/20% Damage reduction (based on tier)
- **Cost:** 1/2/4/8/16 Gold (based on tier)
- **Tiers:** Chipped/Flawed/Regular/Flawless/Perfect
- **Description:** Hardens defenses against attacks
- **Backpack Battles Equivalent:** Amethyst

## Module Mechanics

- Modules can be combined: 3 of the same tier merge into 1 of the next tier
- Modules must be socketed into compatible items to provide their effects
- Higher tier modules provide exponentially better bonuses
- Some items have multiple socket slots for stacking modules
