# Infrastructure (Support Items)

Infrastructure items provide passive bonuses, resource generation, and support effects for your build.

## Basic Infrastructure

### Turbo Button
- **Shape:** 1x1 (1 slot)
- **Effect:** +5 maximum CPU, +1 CPU regeneration per second
- **Cost:** 5 Gold
- **Rarity:** Common
- **Class:** Neutral
- **Description:** Overclocks your processing power
- **Backpack Battles Equivalent:** Mana Orb

### Load Balancer
- **Shape:** 1x1 (1 slot)
- **Effect:** -10% cooldown for all items, +0.5 CPU regen
- **Cost:** 6 Gold
- **Rarity:** Uncommon
- **Class:** Neutral
- **Description:** Distributes processing load efficiently
- **Backpack Battles Equivalent:** Haste Potion effect

### Memory Optimizer
- **Shape:** 2x1 (2 slots horizontal)
- **Effect:** +20% healing received, +2 health regeneration per second
- **Cost:** 7 Gold
- **Rarity:** Uncommon
- **Class:** Neutral
- **Description:** Optimizes memory usage for better recovery
- **Backpack Battles Equivalent:** Regeneration Pendant

### Backup Service
- **Shape:** 2x2 (4 slots square)
- **Effect:** When health drops below 30%: Instantly backup and restore 50% max health (once per battle)
- **Cost:** 12 Gold
- **Rarity:** Rare
- **Class:** Neutral
- **Description:** Emergency backup system
- **Backpack Battles Equivalent:** Guardian Angel

### Redundant Array
- **Shape:** 3x1 (3 slots horizontal)
- **Effect:** All items gain +10% damage, +10% block chance
- **Cost:** 10 Gold
- **Rarity:** Rare
- **Class:** Neutral
- **Description:** Redundancy improves reliability and performance
- **Backpack Battles Equivalent:** Banner of Command

## Sentaur Class Infrastructure

### Schrodinger's Die
- **Shape:** 1x1 (1 slot)
- **Effect:** Battle start: Gain 1 Compute (luck equivalent)
- **Cost:** 2 Gold
- **Rarity:** Rare
- **Class:** Sentaur
- **Description:** Luck generator using quantum uncertainty
- **Backpack Battles Equivalent:** Lucky Clover

### Neural Collar
- **Shape:** 2x1 (2 slots horizontal)
- **Effect:** Items gain 5% critical hit chance for each Compute
- **Cost:** 6 Gold
- **Rarity:** Epic
- **Class:** Sentaur
- **Description:** Neural interface that enhances critical calculations
- **Backpack Battles Equivalent:** Acorn Collar

## Notes

- Infrastructure items provide passive bonuses rather than active effects
- CPU management is crucial for ability usage
- Health regeneration and recovery effects help sustain through battles
- Class-specific infrastructure will be added as new classes are developed
