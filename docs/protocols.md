# Protocols (Accessories)

Protocols are the equivalent of "Accessories" from Backpack Battles. They provide passive bonuses and effects.

## Common Protocols

### API Token
- **Shape:** 1x1 (1 slot)
- **Effect:** Start of battle: Heal for 8
- **Cost:** 4 Gold
- **Rarity:** Common
- **Description:** Basic authentication that provides initial security
- **Backpack Battles Equivalent:** Healing Herbs

### Bitcoin Wallet
- **Shape:** 2x1 (2 slots horizontal)
- **Effect:** Every 3s: Gain 1 Gold
- **Cost:** 3 Gold
- **Rarity:** Common
- **Description:** Cryptocurrency mining generates resources
- **Backpack Battles Equivalent:** Piggybank

### CAPTCHA Module
- **Shape:** 1x1 (1 slot)
- **Effect:** On hit: Inflict 1 Blind
- **Cost:** 2 Gold
- **Rarity:** Common
- **Description:** Obscures enemy vision with verification challenges
- **Backpack Battles Equivalent:** Pocket Sand
