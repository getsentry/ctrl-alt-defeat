# Containers (Infrastructure)

Containers are the equivalent of "Bags" from Backpack Battles. They provide grid space to hold your modules and items.

## Neutral Containers

### Standard VM
- **Shape:** 2x2 (4 slots)
- **Effect:** None
- **Cost:** 4 Gold
- **Rarity:** Common
- **Description:** Basic virtual machine with no special effects
- **Backpack Battles Equivalent:** Leather Bag

### Edge Node
- **Shape:** 2x1 (2 slots horizontal)
- **Effect:** Modules inside execute 10% faster
- **Cost:** 3 Gold
- **Rarity:** Rare
- **Description:** Closer to users means faster response times
- **Backpack Battles Equivalent:** Fanny Pack

### Memory Cache
- **Shape:** 3x1 (3 slots horizontal)
- **Effect:** Gain 1 maximum CPU
- **Cost:** 5 Gold
- **Rarity:** Epic
- **Description:** RAM boost for better performance
- **Backpack Battles Equivalent:** Stamina Sack

### Load Balancer
- **Shape:** 1x1 (1 slot)
- **Effect:** Start of battle: Gain 15 Block
- **Cost:** 2 Gold
- **Rarity:** Godly
- **Description:** Distributes traffic to prevent overload
- **Backpack Battles Equivalent:** Protective Purse

### Patch Registry
- **Shape:** 2x2 (4 slots)
- **Effect:** First Patch deployed: Random buff / 4 Patches deployed: Clear 8 errors
- **Cost:** 5 Gold
- **Rarity:** Legendary
- **Description:** Optimized storage for deployable patches
- **Backpack Battles Equivalent:** Potion Belt

### Container Orchestrator
- **Shape:** 3x2 (6 slots)
- **Effect:** Start of battle: gain 7 Block for each Basic module inside
- **Cost:** 13 Gold
- **Rarity:** Epic
- **Description:** Kubernetes-style orchestration provides baseline protection
- **Backpack Battles Equivalent:** Holdall

### Serverless Function
- **Shape:** 2x2 (4 slots)
- **Effect:** Deploy phase: If has 2+ Legendary modules, generate free API credits
- **Cost:** 5 Gold
- **Rarity:** Epic
- **Description:** Pay-per-use efficiency that rewards rare deployments
- **Backpack Battles Equivalent:** Box of Prosperity

### Chaos Experiment
- **Shape:** Variable
- **Effect:** Game started: Replace with random infrastructure and modules
- **Cost:** 10 Gold
- **Rarity:** Unique
- **Description:** You never know what infrastructure you'll get
- **Backpack Battles Equivalent:** Sack of Surprises

## Sentaur Class Containers

### Network Cache
- **Shape:** 2x2 (4 slots square)
- **Internal Storage:** 3x2
- **Effect:** +2 CPU regeneration. Sentaur items inside have -15% cooldown. 3+ Sentaur items: All Sentaur items gain +15% damage
- **Cost:** 10 Gold
- **Rarity:** Rare
- **Class:** Sentaur
- **Description:** Storage node that optimizes data flow and resource distribution
- **Backpack Battles Equivalent:** Ranger Bag

### Mesh Network Hub
- **Shape:** 3x1 (3 slots horizontal)
- **Internal Storage:** 2x2
- **Effect:** Sentaur items activate 10% faster. Items inside gain +10% accuracy
- **Cost:** 5 Gold
- **Rarity:** Uncommon
- **Class:** Sentaur
- **Description:** Decentralized storage with adaptive routing
- **Backpack Battles Equivalent:** Vineweave Basket
